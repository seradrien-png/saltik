# Sable rouge : corrections et BT

Demande : musique fournie au niveau 5, sable sans colonnes, crâne praticable et solide, collisions des projectiles ennemis sur les Saltiks visibles, marche légère Striker/Gatling, nouvelle tenue BT sur les deux niveaux rouges.

Conserver le moteur natif, les dégâts, l'esquive, les arsenaux, les autres costumes et éditions. Le MIDI est rendu fidèlement en OGG hors ligne pour utiliser l'unique lecteur existant. La géométrie peinte détermine les hitboxes composées et les supports du crâne ; les espaces entre les pods restent vides. Le sable suit des raccords affines continus fixés au monde. La marche ajoute un faible déplacement sous les pivots des jambes, sans détacher les racines ni tourner les roues. Le BT possède ses propres vues, masques et sockets mesurés, et conserve ses seize missiles natifs.

Validation : régressions avant/après pour chaque défaut ; surfaces, orbitage et collisions sur trois personnages ; finitions et retournements du nouveau BT ; musique réelle avec pause/muet/reprise ; campagne normale et tests complets ; navigateur ordinateur/mobile ; paquet sans perte, publication sur le même Site et sauvegarde GitHub sans supprimer les éditions antérieures.
