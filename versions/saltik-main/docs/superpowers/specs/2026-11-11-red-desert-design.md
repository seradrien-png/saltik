# Niveau4 — Le Désert rouge / C-07

User demandé : une traversée calme du désert rouge de référence, en suivant un chemin vers la profondeur avec réduction progressive du Saltik ; entrer dans le bâtiment lointainC-07, nettoyage intense, sortir et revenir au premier plan. Conserver tous les autres niveaux, les trois personnages et les commandes existantes. Image : dunes vermillon, ciel cobalt, ossements colossaux, crâne géant, main enfouie, bunker rouillé. Plusieurs plans opaques, masses et chemins intégrés, aucune plateforme basique flottante.

Réalisation : projection2.5D du déplacement le long d’un sentier fixe dans le panorama extérieur ; les commandes droite/gauche restent réversibles, pas une vidéo automatique. Aller vers la droite pour atteindreC-07 au fond, puis après l’intérieur retour vers la gauche jusqu’au premier plan. Sprite et ombre passent continûment de taille1 à.28 ; les trois modèles actuels restent fidèles. Pas de tirs, sauts ou ennemis à l’extérieur : focusexplorationcalme. Décor opaque, rochers/ossements de premierplan occultent brièvement le Saltik selon sa profondeur.
