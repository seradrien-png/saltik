# Cascade sous le pont : référence reçue

La photo désigne royal-quarter-bridge.png, cascade en gradins sous le pont 3/4. Retouche de mouvement uniquement, avec réalisation autonome déjà autorisée. Préserver eau de fond approuvée, peinture, rails, velours, héros, mécaniques et toutes les autres retouches.

Choix : supprimer le scrolling en six colonnes indépendantes pour ce seul atlas. Un masque précis en cache couvre toute la chute, les filets blancs proches de l’eau et les retombées ; texture native légèrement réfractée sans boucle de morceaux déplacés verticalement. Des filets descendants continus à vitesses propres aux étages et une écume/brume douce localisée donnent la vitesse et le poids. Tout reste dans les pixels d’eau/écume du dessin ; or, velours et transparence protégés. Le même atlas réutilisé au second pont reçoit le même traitement.

Alternatives écartées : refaire la peinture (style déjà réussi), renforcer les colonnes décalées (cause du morcellement), superposer un film rectangulaire couvrant le décor.

Plan natif : tests RED pour masque eau/blanc/or/alpha, déplacement doux borné, filaments descendants/pause/crop. Implémenter src/royal-bridge-water.js et déléguer uniquement kind bridge depuis royal-waterfalls.js. Tests eau/royal, navigateur sur vrai PNG à plusieurs temps et zooms, revue indépendante, build/commit, site existant/public conservé, vérification live puis sauvegarde GitHub existante. Le masque et la texture doivent être calculés une seule fois par image ; aucun pixel-read par frame. Le croppage et la caméra gardent la même transformation que la peinture.

Validation : 32 tests eau/campagne velours verts, puis 17 contrôles finaux verts après ajout des nappes descendantes fondues. Revue indépendante sans défaut critique/important, y compris surface réutilisable et destination-in. Navigateur sur vrai atlas et gros plans : les trois étages changent (3780/32669/83091 pixels entre deux temps), zéro changement hors masque, dans l’or ou dans le transparent ; pause strictement stable ; lecture source initiale unique. Surface liquide de550×566 réutilisée, masque alpha appliqué une fois puis un seul blit ; pas de chemin de pixels complexe appliqué à chaque filet. Mesure locale Chromium logiciel incluant peinture native et readback : moyenne18.3ms/p95 29.4ms ; ne représente pas le framerate complet du jeu. Les images d’origine, arrière-plan approuvé, sauts, anguille, arc, mécaniques, commandes et autres niveaux restent inchangés.
