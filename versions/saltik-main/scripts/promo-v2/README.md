# SALTIK — cinematic voiced trailer revision

User rejected the first gameplay montage as insufficiently edited/professional and requested tighter cutting, voices, intense native gameplay, character emphasis, created assets as needed and a final commercial voice. Full creative direction delegated; only game Saltiks may appear.

22-second Full HD edit, 31 timed segments including two short dramatic silences, alternating native Striker/DR-01/green-orange hero plates and detail shots, typography and six newly captured close-up combat takes. The three characters use the exact game drawing functions and material maps, never regenerated character paintings. Gameplay takes use unmodified simulation, ordinary inputs and the native renderer, rendered at 3840×1620 before a controlled crop to Full HD. Generated asset radar-canyon.png is environment only and is used solely for the cinematic character plates; gameplay remains the actual game scenery and is labeled IN-GAME.

The action/detail shots deliberately use tight optical framing, including the antenna tip reaching the top edge during a jump in the final take. Full-body identity is established by the earlier portraits; the underlying model is unchanged. Independent source and frame review found no Critical/Important issue. The reported HD color-matrix minor was corrected with explicit Rec.709 conversion and encoding tags. Final decoding, voice intervals, loudness, phone/desktop playback and download were checked separately.

Seven voice cues: native Saltik detected / ready / target lock / grab him, a natural synthetic narrator saying “They built you to obey” and “Choose your own way”, then the explicit commercial line “More to come on your smartphone.” Narration/advertising are original en-US-GuyNeural synthesis via Edge TTS, no cloned performer. Saved MP3 masters are in assets, so reproduction does not require a voice service. Package was configured to trust the managed system CA bundle, with TLS verification kept enabled. The combined narrator master is retained as an alternate; the edit uses the two separate sentences.

Audio combines the existing project epic score, original trailer percussion, risers and impacts, and speech-driven ducking. Voice cues/timing are logged in voices.json. The final mix scales before PCM conversion rather than clipping, then masters to -15 LUFS / -2dBTP target and stereo AAC 48kHz.

Reproduce in this workspace (Python Playwright, Chromium, ffmpeg, NumPy/SciPy): first `python scripts/promo-v2/cache_actions.py`, then `python scripts/promo-v2/export.py`. Temporary server uses 4178; action frames and masters live under /workspace/recovery-saltik/promo-v2. The music input is the project-owned Feral_Steel_Saltik_Foret_Epique_ORIGINAL.ogg downloaded earlier in this task. Runtime deliverable remains dist/video/saltik-gameplay-promo.mp4 plus poster and the existing promo.html page; original gameplay/outro are unchanged.
